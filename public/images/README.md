# Product image sources

Every file under `public/images/` is a flat SVG illustration generated by
`scripts/generate-product-images.py`, written for this repository. Nothing here
was downloaded, traced from, or derived from a third-party image, so the whole
set is ours to publish with no attribution or licence obligation.

Naming: `<product-slug>/<color-id>-<n>.svg`, where `n` is 1, 2 or 3 — three views
per colour. The colour ids match `OptionValue.id` in `src/server/demo-data.ts`.

To regenerate after changing a product's colours:

```bash
python3 scripts/generate-product-images.py
```

The images depict invented products. They are not photographs and are not
intended to resemble any real item.
